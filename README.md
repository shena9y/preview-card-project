# NFT Preview Card Component

A solution to the **Frontend Mentor** "NFT preview card component" challenge, built with HTML & CSS. The dark-themed card displays the *Equilibrium #3429* NFT with its image, ETH price, time remaining, and a creator footer with an avatar — plus a hover "view" icon overlay on the artwork.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Frontend Mentor](https://img.shields.io/badge/Frontend%20Mentor-3F54A3?style=for-the-badge&logo=frontendmentor&logoColor=white)

## ✨ Features

- 🖼️ NFT artwork with a hover-activated **view icon overlay** (smooth 0.5s transition)
- 💎 Ethereum price row (`0.041 ETH`) with inline SVG icon
- ⏳ "3 days left" countdown label with clock icon
- 👤 Creator footer with avatar image and "Creation of Mohammed Hamdy" text
- 🌑 Dark theme (`#0d1a2d` background, `#15273f` card) with a soft shadow
- 🧱 353px centered card with rounded corners

## 🛠️ Tech Stack

- **HTML5** — card markup
- **CSS3** — Flexbox, positioning, hover transitions & box shadows

## 📂 Project Structure

```
├── index.html        # NFT card markup
├── css/
│   └── style.css     # Dark theme & hover effects
└── images/           # Artwork, icons, avatar & favicon
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shena9y/preview-card-project.git
   ```
2. Open `index.html` in your browser — no build step required.
